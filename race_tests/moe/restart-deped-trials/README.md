# Restart-dependent trial archive

This directory is the persistent archive for AKO4ALL exploration that does not qualify for promotion.

Archive a concise report here when a direction is rejected, regresses, fails correctness, remains inconclusive, or measures below the repository's **1.2%** promotion threshold. Each report should include:

- starting commit and source/configuration;
- correctness and import-validation results;
- paired benchmark/profile evidence;
- the hypothesis tested and the reason for rejection or pause.

Archived trials do not receive version numbers, branches, submission updates, or `dorm` advancement. See [`../RESTART_POLICY.md`](../RESTART_POLICY.md) for the full project-level AKO4ALL overlay.
