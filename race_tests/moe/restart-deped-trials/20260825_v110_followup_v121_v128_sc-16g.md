# 2026-08-25 v110 follow-up v121-v128 rejected trials（sc-16g）

所有试验都以 exact v110 SOTA（SHA256 `439a2b80...`）为父版本，遵循 OJ allowlist、完整正确性和同进程 AB/BA；候选门槛为至少 `1.2%`。本批没有任何被拒方向进入 `restart-submission`。

| Trial | 单一机制 | 结果 vs v110 | 决策 |
|---|---|---:|---|
| v121 | Case2/3 Step2 合并 native row predicate | Case2 `+0.022%`，Case3 `+0.199%` | noise/regression |
| v122 | Case1 Step2 同时假设 `bx/by` 有界 | Case1 `-0.555%` | below gate；资源/代码形态不理想 |
| v123 | 仅假设 `bx` 有界 | Case1 `+0.171%` | regression |

| v126 | 标量 `T.if_then_else` 重写 CTA 映射 | 未计时 | generated C++ `27.7→41.4 KB`，条件展开33次；codegen reject |

## 因果边界

1. Case1 grouped mapping 的 `by` 守卫并非纯浪费：全删会扩大活跃加载状态；`T.assume` 小幅获益但不足门槛，模运算形式明显回退。
2. 显式 TileLang loop 不会绕过后端 buffer bounds 合法化，且会增加寄存器；不再重复该写法。
3. Cases2/3 的 64-KiB prepack bridge 有实际价值：去掉 shared/barrier 后，非合并 global 访问造成约 0.8% 端到端回退。
4. `mcProfiler` perfcount 通道仍报 ret 800；不使用失败 run 的任何 counter 数值。
