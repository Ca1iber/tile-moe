# v091 scripts

- `run_v59_fullcheck.py`: full padded-output correctness and paired device-event benchmark.
- `validate_oj_submission.py`: OJ source/generated-code compliance validation.
- `capture_codegen.py`: generated device C++ and resource capture.
- `profile_submission.py` and `run_paired_mctracer.py`: paired mcTracer capture.
- `extract_metax_isa.sh`: final xcore1000 MetaX ISA and resource extraction.

Exact inputs, protocols, SHA values, and conclusions are recorded in the v091 report.
