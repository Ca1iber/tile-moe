# v104 scripts

These scripts are copied from the validated v102 harness and archived with v104:

- `capture_codegen.py`: generated device C++ and resource capture.
- `run_v59_fullcheck.py`: full padded correctness plus AB/BA timing.
- `validate_oj_submission.py`: OJ import/source/generated-code validation.
- `profile_submission.py`, `run_paired_mctracer.py`, and `summarize_three_kernel_trace.py`: three-kernel trace workflow.
- `extract_metax_isa.sh`: final MetaX ISA extraction.
- `validate_iteration.py` and `summarize_iteration.py`: strict archive validation and manifest inventory.
